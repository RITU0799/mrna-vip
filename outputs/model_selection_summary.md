# Educational Model Selection Summary

Selected model: **Logistic Regression**

- Held-out accuracy: 0.710
- Held-out precision: 0.708
- Held-out recall: 0.694
- Held-out F1: 0.701
- Held-out ROC-AUC: 0.791

The model was selected using F1 on the same held-out split used for reporting these metrics. Therefore, these results are exploratory and the test split is not an independent final evaluation after model selection.

This is an educational model trained on the supplied dataset. It is not clinically validated and must not be used for real patient-care decisions.
